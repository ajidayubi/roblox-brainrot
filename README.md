# Brainrot Bay — a make.fun roblox-brainrot-01 entry

Brainrot Bay is a 3D Roblox game where players catch absurd meme-born brainrot characters walking along a conveyor, place them on their base to earn money per second, climb rarities from Common to Secret with Golden/Diamond/Rainbow/Void mutations, lock their base against the Sneaky Raccoon, outrun the tsunami wave, and rebirth for permanent multipliers.

## How to run

Build the place with:
```bash
rojo build default.project.json --output game.rbxl
```

Hand in with:
```bash
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

## Characters & Rarities

- Noodle Cat — Common ($5/s)
- Sir Reginald Pigeon — Common ($8/s)
- Professor Pickle — Rare ($15/s)
- Sir Quacksalot — Rare ($22/s)
- DJ Toaster — Epic ($40/s)
- Captain Cactus — Epic ($60/s)
- Grandma Rocket — Legendary ($95/s)
- The Forbidden Burrito — Legendary ($150/s)
- Quantum Llama — Mythic ($230/s)
- King Spaghetti — Mythic ($340/s)
- The Almighty Sock — Secret ($600/s)
- Disco Shark — Secret ($900/s)
## Mutations and events

Spawned brainrots can carry Golden, Diamond, Rainbow, or Void mutations that multiply their cash generation.
A tsunami wave sweeps through the central plaza on a timer, causing any players caught outside safe zones to drop their cargo.
The Sneaky Raccoon attempts to rob unsecured player plots, which can be prevented by installing base locks that temporarily deter the thief.
